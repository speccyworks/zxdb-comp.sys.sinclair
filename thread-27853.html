Thanks very much for the feedback. 
I get the same problems with the file you mention with a real +2
machine, so it's not Spectaculator's fault.
Looks like there are two problems here, both due to the "memory
overlap" issue. There's a big datablock which gets loaded into a
memory location that overlaps the source file, which is probably why
there are glitches in the song. The same datablock also overwrites the
BASIC area, which is why the song doesn't exit properly. The former
should be fixable by shifting the source file to an unused memory
location before doing the load, but I'm not sure there will be enough
free memory realestate to save the BASIC area and restore it after
playback. Nevertheless, I'll look into this. 

>I look forward to getting hold of the source :)

Hmmm. Source... well, there isn't any really :-) It's mainly written
in Spectrum BASIC (no chuckling at the back) with a few M/C routines
thrown in. I (perhaps foolishly) didn't keep the disassembly of the
m/c bits, but WinZ80's debug option will get it back. It's not exactly
complex stuff :-) 
The PC-based bit doesn't really do anything except create a checksum
and write out a TAP file. You're welcome to see the source code for
that bit, but it's very dull :-)

Thanks again for the feedback - it's very much appreciated! 

Tim.
