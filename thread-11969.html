Warajevo uses a TAP format slightly diferent from the standard TAP that most
emulators use... try converting a TZX file into a TAP file and load the
generated TAP into Z80 or X128, for example. Actually, the Warajevo's TAP
format is somewhat similar to the TZX format, as it contains loading speed
informations and other things...
It's really hard to convert a TZX file into the standard TAP file, I just
succeeded with about 5% of my TZX archive.

On Sat, 25 Apr 1998 01:21:20 -0300, "|Bugs |Bunny" 
wrote:

>>.... (The exception here is
>>Warajevo, which does a very good job of loading turbo-loaders from
>>either standard or it's own .tap files).
>
>Warajevo uses a TAP format slightly diferent from the standard TAP that most
>emulators use... try converting a TZX file into a TAP file and load the
>generated TAP into Z80 or X128, for example. Actually, the Warajevo's TAP
>format is somewhat similar to the TZX format, as it contains loading speed
>informations and other things...

It actually doesn't contains any such info... it only has standard speed blocks
(as in TAP files, but Warajevo can autodect the loader (speed, etc.) used in
most of the loaders) and the direct sample support (as a VOC file (8 times
smaller actually) or the direct recording block in TZX) ... so you cannot do a
direct WarajevoTAP->TZX conversion as you would expect (with the turbo loading
blocks, etc. properly converted), for this you would need to do
WarajevoTAP->VOC->TZX.

>It's really hard to convert a TZX file into the standard TAP file, I just
>succeeded with about 5% of my TZX archive.

Thats the reason why TZX files exist ... since TAP cannot hold all the extra
info TZX can...
