2002-11-05 16:32:15 Andrew Owen 
Hi there folks,

My name's Troy McClure. You may remember me from such classic movies as
'Who Stole My Aardvark', and 'There Goes The Neighborhood". I'm here to
tell you about this new fangled thing called SE Basic. Apparently there
was a bug in the last version which led to several people being needlessly
electrocuted, but I'm assured that that's all sorted out now, and the
relatives of the deceased are very happy with their complementary ZX
Spectrum SEs. There's also something very special about this version so
I'll hand you over to Evil Geniuh, er, I mean creator, Andrew Owen...

You can use this version on a real machine without the use of a soldering
iron. There's a tape file which you can use on real hardware. It's meant
to be used on a 48K machine or a 128K machine in 48K mode. Just load it
into your Spectrum using your utility of choice (Taper, WinAmp with the
.tap player or whatever). You will then have a 32K Spectrum running SE
Basic. You'll only be able to use programs that don't use the top 16K of
memory with it, but at least you'll get a chance to try it on a real
machine before you decide whether you want to get the soldering iron out.

Download it here:

http://www.worldofspectrum.org/sinclairbasic/sebas072.zip

And email me about any probelms you have with it (which *should* be none).

  I like flashing blue cursors. In the TAPROM archive on nvg, I've got a 
program that patches the standard cursor to flashing blue, and the syntax
error cursor to flashing red. I wish Sinclair had done that on the 128. 
("colcur" in "rompoke.zxt" in "taprom.zea").

  Here is an assembly listing of the changes made; obviously in SE BASIC,
you wouldn't have all the spaghetti that I indulged in to get the code 
into the existing spare space.

	org	25h	;3 spare bytes
	exx
	jr	2Bh	

	org	2Bh	;5 spare bytes
	ld	hl,(ATTR_T)
	jr	5Fh	

	org	5Fh	;7 spare bytes
	push	hl
	ld	hl,0D7h	;Bright red/white
	jp	18CAh

	org	189Eh	;Draw ? cursor
	call	25h	;instead of 18CAh

	org	18C6h	;Draw K/C/E/L/G cursor
	ld	hl,0CFh	;Bright blue/white
	nop		;Replaces RES 7,H ! SET 7,L in original ROM
