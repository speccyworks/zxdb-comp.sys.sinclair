CRAPPY '97
----------
Last year's C.S.S. Crap 60 was utterly abysmal - thank you all! This year we're
hoping for more of the same only worse, so here's what you need to do if you'd
like to participate :

1. Download the old compilation and have a look at the sort of entries we had
   last year. Your entry must be WORSE! Okay? I feel the need to progress with
   this year's compilation, so we'll have no more 'semi-good' games (i.e. ones
   produced with 3D Game Maker, 3DCK, etc.). You may also wish to check out 
   Cascade's Cassette 50 to see how the 'professionals' do it! This is what 
   inspired the compilation last year.....

   ftp://ftp.nvg.unit.no/pub/sinclair/snaps/games/misc/CSS_Crap_Games_Comp.zip
   http://mudhole.ehche.ac.uk/‾blood/
   ftp://ftp.nvg.unit.no/pub/sinclair/tapes/c/cass50.zip

2. Do your worst! Produce a game or two (or three!) which fits into the style
   of the compilations above.

   NEW this year, a few rules! These are they :
   1. Programs must be of your own doing, not type-in listings or stuff you
      found on the Internet.
   2. Programs must be GAMES - no database programs, no biorhythms calulators,
      no music demos.
   3. Programs must RUN! Sending me a program that is crap because it doesn't
      work is cheating! ;-)
   4. Programs must work on a 48k machine. If it runs on a 128 then fine, but
      it must also run on the basic machine.
   5. Programs may be old ones you wrote years ago or brand new ones you coded
      this week. If writing new ones, it'd be nice to have a few 'spoof' crap
      games..... :-)

3. Send them to me in whatever format you deem necessary (i.e. snapshots,
   TAP files, etc.). If your program is to be a snapshot, it'd be really
   helpful if you coded it so that the RANDOMIZE happens after you start the
   game, so that you get a random game each time (rather than the same game
   every time you load the snapshot).

   All entries to :
   …@…

   NO ENTRIES TO :
   …@… - this email is NOW DEFUNCT, so don't use it!

   Don't forget to include a brief description of your game and some basic
   instructions on how to play (if it's not included in the game itself).

4. Closing date for entries to be announced, but probably sometime after 
   Easter. Any questions, drop me a line.



Cheerio!
