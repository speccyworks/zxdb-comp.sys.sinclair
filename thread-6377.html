3 posts, 1996-05-30 – 1996-06-05

1996-05-30 …@… 
I've got hold of an unreleased, but virtually comleted, Spectrum game. It's a 
two part (2x48k) PAW adventure game called 'Gallileo and the Correcting 
Prism'. Unless I'm mistaken this will be the first game to be released for 
Spectrum emulators, rather than the Spectrum itself.

A web site will be set up in the next few days giving more details - I'll 
post the URL to this group.

On Monday 17 June the remaining bugs should have been fixed and the game will 
be made available for download at the web site. Free of charge - of course! 
Does anyone have a preference for the file format: SNA, Z80, etc?
