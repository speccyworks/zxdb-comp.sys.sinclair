New search script changes, and quite a few tips to keep you going 

* Updated the search script. You can now specify exact string matches.
I've also modified the alias list substantially, based on The Italian
Project
findings and the aliases used on WOS. Because of the sheer number of
aliases searched, I've changed the default alias lookup from on to off.
So if you want to search through the alias list, you have to specify it.
You can use either of these new functions by using the check boxes
or using the correct parameters (checkalias=y or exactname=y). It also
displays links to WOS' Infoseek for each result. I hope you find these
new additions/modifications useful, but please let me know if you have 
any problems with the new script.
