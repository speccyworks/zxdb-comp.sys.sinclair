CSSCGC entries and ZXDB

The comp.sys.sinclair Crap Games Competition (CSSCGC), 1996–2026, next to ZXDB's contest lists: entries ZXDB lacks, entries without the contest tag, authors the posts name, handles and real names, hosts, and alternative titles. Where an organiser posted a full list (1996, 1997, 1999, 2007–2010, 2014), every entry is in ZXDB.

1999: the judge reviews an entry called "Arcade Emulator" (1999-06-15). His list has 42 games and so does ZXDB's; the only ZXDB entry not on his list is Advanced Test Failure (30613), and his description ("your favourite arcade game is now pushing up the daisies because of it's corrupted ROM") fits it. It is probably an alternative title.
2008: "VMWare for the ZX Spectrum" by James Smith, 6th place (2009-01-14), is ZXDB's Virtual ZX Spectrum (31101).
2022: Jim Waterman's first entry, "Big Clives Supergayrainbow Ulaplus Bear Flag Edition" (2022-01-07), is probably ZXDB's Big Clive's Supergayrainbow Exploding USB Power Supply Game (36973, 2022 list, ULAplus); the posted name could be added as an alternative title.
2014: the post calls it "Jet Set Willy v0.1" by Spud; ZXDB has Jet Set Willy v1.0 (31367).
2001: Tunnel Escape 2 by Mike Wynne is in ZXDB twice: Tunnel Escape 2 (30737, tagged) and Tunnel Esc. 2 (17815, untagged).
2003: A.J. Moss's C64 BASIC emulator fits two entries: C64 Emulator (30782, his, no files) and Commode 64 BASIC (37342, no author, has a tape file). They may be the same game (2004-01-30).
1999/2000: Andrew Owen sent Commodore 64 Simulator, SK Print and The X-Pensive Demo for 1999 (1999-03-26), but they are not in the judge's full 1999 list. ZXDB has them in 2000, which is probably right: lost in 1999 and entered again.
