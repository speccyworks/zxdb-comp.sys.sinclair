1997-06-17 12:12:57 address hidden Warajevo 1.7 in development
I want to inform readers of this workgroup that Zeljko and I prepare new
version of Warajevo, most probabbly 1.7. I think that this will be last
DOS release, then we will switch to Windows 95.

New features:

- Accurate timing of instructions, still in development, but we hope that
we will sucess to make real-time emulation, may be with rainbowing
effects.

- Sound Blaster support, including MIDI interface.

- Users shell will be in graphic mode (with hourglass mouse cursors,
nicer checkboxes, and picture of the current snapshot) or in
text mode as in 1.5 release

- Fixed some bugs in user shell ( loading using SoundBlaster will be
better, SPACE key in edit snapshot) and emulator (sometimes microdrive
file in previous version was truncated)

- Improved speed of users shell ( Switching from emulator to shell is
done in less than one second, even if current tape file is on floppy
disc, many database operations are accelerated, simplified entering
of tape file name in database, compression requires less RAM)

- Added convertors for new tape formats (BLK, LPT, TZX, ZX Brukner, and
 Roman & Easy in both directions), snapshot formats (SIT, SEM, SLT,
SNP, SNA 128), enlarging of MDR to maximum size, database format
(SpecPice, ZX Rainbow and SGD). Snapshot to TAP now has additional
capabilities.

- Start button! In bottom left corner :-). Click on it, and select the
file. It will be automatically in few seconds converted to temporary file
and started.  Currently I support:  - Z80, SNA, SNA128, SIT, SEM, SLT,
SP, VGASPEC SP, PRG  - Warajevo TAP, Lunter TAP, BLK, LPT, TZX (only for
standard, turbo  and pure data blocks).  - MDR


- I will look the grammar in manuals. It is REALLY boring. Any native
English speaker wants to do it?

- I am not yet sure about direct using of SLT and TZX in emulator and
network emulation.


Suggestions? Remarks?
