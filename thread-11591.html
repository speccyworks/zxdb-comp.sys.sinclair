1998-03-09 …@… CSSCGC Crap Games Contest 1998
Hi everyone,

Seeing as nobody else came forward as a judge there will now be two
judges namely myself and Alistair Nelson.

I've set up two mailing lists, an archive and a standard mailbox over
here but more on that in a minute. Firstly, I'll just go over the
rules:

Rules:
======

 1. Entries *must* be written by you. (Obvious really - Ed) If it's
discovered that your entry has previously appeared in *any* Computer
Magazine as a type-in listing (e.g. Sinclair Programs and Sinclair
User) it will be disallowed.

 2. At 00:00 UTC on the closing date the mail server will be set to
bounce all mail to the entries address. (fnar! - Ed)

 3. The judges decision is final and no correspondance will be entered
in to.

 4. In keeping with Fidonet tradition there is no rule 4.

 5. All entries should be supplied in a format that will run in X128
as that is the Emulator that we'll be using. TZX files are preferred
as we can also check them on a real Speccy (a +2 in my case, don't
know about Alistair) without too much difficulty, followed by TAP,
then Z80/SNA. Send me the program on Cassette in a Jiffy Bag if you
have to and, if all else fails and it's in BASIC send me the listing
by e-mail!

 6. You may use whatever programming system you want as long as the
resulting program works as detailed in Paragraph 5. :)

 7. If you plan on making a TZX file do a crap loading screen as well
so we can have a laugh. (fnar! - Ed) A sample loader (for anyone who's
forgotten how to do them) is given below.

Sample Loader:
==============

10 BORDER 0 : PAPER 0 : INK 0 : CLS
20 LOAD "" SCREEN$
30 LOAD ""

Instructions:
=============

If you have any queries about the competition please send e-mail to
csscgc-admin (at) salterg (dot) demon (dot) co (dot) uk and one of us
will get back to you asap

When you've finished your entry send it to csscgc-entries (at) salterg
(dot) demon (dot) co (dot) uk with a subject line along the lines of
"CSSCGC 1998 : Entry n from Your Name" so that we know who it's from

If you want to look at the entries that have been received send a
message to csscgc-entries-archive (at) salterg (dot) demon (dot) co
(dot) uk with "INDEX" as the subject

Once we've decided on the winners (top 20) we'll post them (*not* the
binaries - Ed) to the group, zip all of the entries up (after having
renamed them to TLAs and making them into a TZX and TAP file) and put
the archive up on my Demon web space.

The closing date for entries is Monday 13 April 1998 and any entries
received after that date will be disallowed.

Cya,

Barry
