To celebrate the release of a feature complete version of SE Basic
with the new default palette for ULAplus, here's a website with the
download and all the details:

This really is the final release candidate. Don't expect a new release
until you can actually buy a ULAplus. Any information on compatibility
fixes for hardware that uses the /ROMCS line and interfaces with BASIC
is most welcome and will be included in a future release.
