2010-02-19 01:18:43 OwenBot ZXDB: OpenSE BASIC
I'm pleased to announce SE Basic RC1. This is almost feature complete
(there are 66 bytes left) and fixes some issues with Beta 2. Same link
as before (and same file name, but different contents when you expand
the zip file).

http://bit.ly/d64mo3

Even those with no interest in SE Basic may be interested in the
release note as I have included complete 8 octave note tables for all
three variant clock speeds of the AY chip found in official and
licensed machines.

2010-02-23 10:51:07 OwenBot Re: ANN: SE Basic RC1 / AY note tables
I have updated the RC4 notes as there was an error in the +2A/+3
paging section. I have changed the wording of the credits as requested
by the major contributor. I have added all the names I can think of
for those may or may not have contributed code.

I added the footnote because of a number of misleading posts on WoSF,
including the statement: "You can't simply shorten error messages by
using tokens as any character over 127 is used to mark the end of the
message and all tokens are over 127." Well I did shorten the error
messages by using tokens. Open the ROM in a hex editor and look at the
error messages if you want proof. :)
