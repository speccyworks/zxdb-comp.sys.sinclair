This is an 'ideal' 128 that will run the majority of software written
for the 48K and 128K machines correctly (unlike the five official
128s, all of which have various issues). The specification is aimed at
emulator authors but you can create a compatible machine in real
hardware by modifying a +2A.

2010-06-10 08:40:24 OwenBot Re: ZX Spectrum 128Ke
The css FAQ has most of the details. There is an errata at
http://scratchpad.wikia.com/wiki/ZX_Spectrum_128

Notably, the UK 128 has contended ports 1, 3, 5 and 7, not 4-7 (as
stated in the manual). This is why the sampled sound in Chase HQ only
plays properly on the +2A/+3.

The UK 128 has a modified version of BASIC in place of the original
48K ROM which prevents games that checksum the ROM as a copy-
protection measure, e.g. Travel With Trashman, from loading, and games
that use the blank area at the end of the ROM as an IM2 table, such as
Bomb Jack, from working.

The UK 128 returns the floating bus when you read the AY ports,
contended port reads, and will crash if you read from port 7ffd (as
the floating bus is immediately written back to the port).

The Spanish 128 also has a missing line on the edge connector.

Despite the hype, the best 128 to own is a modified +2A with the
Spectrum SE ROM set, rewired joystick ports and edge connector, and
the floating bus mod.

-Andrew
