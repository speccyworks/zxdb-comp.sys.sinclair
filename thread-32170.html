4 posts, 2006-04-27 – 2006-05-01

2006-04-27 08:55:51 …@… 
Just poking my head in to announce SP1 for z88dk.  SP1 is the next
version of splib, a flicker free sprite engine written in asm that can
be called from C, asm or a mixture of the two.  The underlying display
algorithm has remained approximately the same as the last version of
the library (splib2) but a lot of interesting things have been added
too.

This time I will be attempting to port SP1 to several platforms,
including MSX1, Amstrad CPC and ti-calculators.  This means that games
written with SP1 should be (relatively) easily ported across machines.

You can get SP1 and other new additions to z88dk by grabbing the latest
cvs repository for z88dk.  I have started a thread on WOS
<http://www.worldofspectrum.org/forums/showthread.php?t=11729> that
describes how to do this for Windows owners and will put there some
test programs in the next week or two to help me debug the library and
help you understand how it works :)

Previous versions of splib have been bug-free, but I do not have that
confidence this time around.  SP1 was written over several months this
time and I changed my mind twice how things would work.  The result has
been code complying with three different ways of doing things and long,
painful debugging sessions over the last few weeks.  I hope all the
hidden bugs will be discovered in the near-term with the help of the
test programs being put together to find them.
