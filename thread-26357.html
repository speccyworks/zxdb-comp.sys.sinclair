I was wandering through old disks the other day and
came across some old stuff I'd half-written for the
2068.  Among them was a sprites package for the
512x192 video mode.  Over the last few days, I finished
it up and half tested it (it probably works) and thought
why not commit it to 'net memory for posterity by throwing
it onto alt.binaries.comp.sinclair in case someone
somewhere can make use of it.

What's in there:
- commented z80 source, ready for cross-assembly
using tasm.
- any size sprites that are rotated vertically and
horizontally by sw for smooth animation.
- a 64x24 "text" background where text can = udg
style graphics.
- a dynamic block memory allocator

I'm not sure if I succeeded in making it fast
enough for busy games, but there is still
room for improvement, particularly in the movespr
subroutines which I didn't try really hard to
optimize.
