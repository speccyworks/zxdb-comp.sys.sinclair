Actually the ZX81s CPU was 93% the speed of the Speccy (3.25Mhz vs 3.5MHz).
However, as you say the Z80 in the '81 has to generate the screen itself, so
approx 70% of it's speed isn't available to programs (Unless you turn the
screen off - ie fast mode).  This is the same reason you can't generate a
screen while loading a progrm - there simply isn't enough CPU time left
over.

2003-10-10 14:22:31 Mike Wynne Re: ANN: New SP81 Out
"Matthew Westcott" wrote...
> Assuming it can handle 48K stuff, presumably it's now possible to run a
> ZX81 emulator on a Spectrum emulator on a ZX81:

Alas it's not quite that simple.  Because of the ZX81 architecture, it's
impossible to execute code above address 32767 (The combination of A15 and
M1 is used to denote video generation).  You can read and write data at
addresses>32767 - even put the stack there but not actually execute things
(This isn't quite true, you can execute instructions if bit 6 of the opcode
is set. Anything else gets executed as a NOP).

Hence a 48k BASIC program would work fine, but a 48k m/c program probably
wouldn't.

MikeW
