Okay, I may not be too successful on the old MIS/MIA front, but I did come
across one or two interesting finds today in my Speccy collection. I had
dragged it out the loft to see if I still had my copy of Ollie Octopus'
Sketchpad (I didn't).

Anyway, I came across a program I used to love, called "Infoload". I think
it was a probably a Program Pitstop type-in from YS. It allows you to peek
into a program as it loads (sort of) and find the (very) occasional hidden
messages.

Basically, you load this program and when it prompts you, you load a game
tape (the game won't actually load properly though, so don't expect to be
able to play it when it stops reading data). As the data is read, it appears
on the screen, kind of. Actually, what appears is usually gibberish but
sometimes (very occasionally) reveals something else that might be hidden in
the code.

Chances of you finding hidden cheat modes or infinite lives pokes or
anything are quite slim - but it can be fun. Given that I was never that
technical, couldn't hack or program in machine code or anything, I had loads
of fun trying to examine my favourite games. The drawback is that some games
with different loaders will not work.

It may well be available on the web somewhere, I don't know, but I've put
together a TZX of it anyway. I have also included a game in the TZX file
(Bomberman I think) just to give you an example, and posted it in ABCS. It
doesn't give you much in the way of hidden messages, but it shows you how
the program works. When the screen becomes full with data, press a key and
it will start the next screenful. I was going to include Super Robin Hood,
as it does have a hidden message, but then remembered that I'd effectively
be distributing a game for which distribution permission has been denied. If
any of you have Super Robin Hood, real tape or a TAP/TZX, I suggest you try
it.

I think I remember how it all works so if there are any questions, just ask.
You have no idea about the wave of nostalgia that swept over me when I found
this tape. Not only that, but I may also have found "International Skodas",
my first ever Crap Game![1] See old threads in CSS for details!

I also discovered the old "Dataquest" program (the database prog that came
with that Quest magazine or whatever it was called), so let me know if you
want a Speccy program that details top wine producers, fish producers, time
zones, average heights, jungle areas, national dishes, etc.

Len

Well, I found that on both copies the basic loader seems to be pretty
unrecoverable. (Anybody know of any tricks to try? I've managed to improve
some by copying onto a newer tape, but is there anything the software can
do? I use Taper, and I've no idea what half the technical details (pulse
etc.) actually are.)

However, the loading screen and game are totally intact. It was
unbelievable, seeing it again after all this time (I estimate it to have
been written round about 1988). Just some of the many features:

- 128k only sound!
- Elements of the plot that once seemed topical! (Kylie & Jason, switching
to unleaded petrol)
- Several spelling errors! (mostly of "skoda" but one of "diabolical")
- Jokes that must have seemed funny when I was in primary school!
- Quickest and easiest game to complete... ever!
- Virtually no playability!
- One scene even has a graphic!
- The promise that my next game was to be "Attack of the Killer Barbie
Dolls"! (Close... in fact, my next game was "Revenge of the Killer Barbie
Dolls", and it was never completed)
- A plug for "M&S Software" - my main rival in the crap software scene,
seeing as the "S" stood for "Steven", my brother.[1]
- A badly directed GO TO statement, so that whenever you start a new game it
warns you to stop the tape!

Ah, the memories.
