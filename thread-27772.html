The actual mechanics of reading tape images (whether they be TZX, TAP or
anything else) is fundamentally pretty trivial[1]: all you have to do is
flip bit 6 as returned by the ULA every time an edge occurs on the tape.
No patching of opcodes required :-)

[1] ignoring flash-loading or equivalents.

Practically, this involves a lot of boring code to deal with all the
different block types...

The TZX format tells you how many t-states that bit 6 is high and low
for.  You have to count t-states while you process instructions and
pass these amounts on to your TZX decoder.  After so many t-states
occur, you toggle bit 6.
When you handle the 'in' and 'out' instructions you have to emulate
the ULA registers, which allow you to control not only the tape port,
but the ram/rom banks on the 128k machines etc.

It's a pretty tough format, but once you get the hang of it and you've
done the 'normal' style blocks, the speedlock blocks are easy.  I also
think it's pretty hard to instantly load a TZX, except by running the
emulation faster.  But I guess this is by design.

You don't need to implement Spectaculator's "autoplay" feature to load from
tzxs as long as there's a way to start playback manually.

I don't use traps anymore in the ROM for this as it broke some obscure
loaders. The best method (my current one) is to examine the machine code
around PC when a program in continuously INning from the same address.

All "looking for an edge" loops in all loaders are nearly exactly the same
(think DI needed a specific check). Don't do this on every IN though, it'd
be far too slow. Just check once/frame.

Here's Spectaculator's routine that checks whether a loader is present at
address wAddr. You should be able to get the gist of what it does.

There are a couple more special cases I need to add as Spectaculator does
auto stop when it shouldn't on a couple of obscure loaders.

Hope it helps :)




// Neat routine to check whether a tape loading routine is present
// at address wAddr.
BOOL
CTZXPlayer::IsLoaderPresent( WORD wAddr )
{
  WORD wInsPtr;
  BYTE chMem;
  BOOL fStop = TRUE;  // Stop unless we find a reason not to
  m_fCheckAutoStartStop = FALSE;

  // First do an test for a generic loader. This accounts for 99% of
  // all cases.
  for( wInsPtr = wAddr; wInsPtr < wAddr+3; wInsPtr++ )
  {
    chMem = m_lpZXDeviceContainer->MemoryRead( wInsPtr );
    if( chMem != XOR_C )
      continue;

    // We've found an XOR C near the IN A,(#FE). AND #20
    // or AND #40 must follow
    chMem = m_lpZXDeviceContainer->MemoryRead( ++wInsPtr );
    if( chMem != AND_n )
      break;

    chMem = m_lpZXDeviceContainer->MemoryRead( ++wInsPtr );
    if( chMem != 0x20 && chMem != 0x40 )
      break;

    // Finally, we look for a JR Z to determine we are infact
    // in a loader.
    chMem = m_lpZXDeviceContainer->MemoryRead( ++wInsPtr );

    // Search Loader quirk
    if( chMem == RET_C )
      chMem =  m_lpZXDeviceContainer->MemoryRead( wInsPtr + 2 );

    if( chMem != JR_Z && chMem != JP_Z )
      break;

    fStop = FALSE;
    break;
  }


  // SPECIAL CASE: Sprite Novaload uses an unusual loader so we must check
for
  // this separately.
  if( fStop )
  {
    chMem = m_lpZXDeviceContainer->MemoryRead( wAddr - 3 );
    if( chMem == INC_L )
    {
      chMem = m_lpZXDeviceContainer->MemoryRead( wAddr );
      if( chMem == AND_H )
      {
        chMem = m_lpZXDeviceContainer->MemoryRead( wAddr+1 );
        if( chMem == JP_Z || chMem == JP_NZ )
        {
          fStop = FALSE;
          TRACE0("NOTE: Special case: Sprite Novaload detected. Not stopping
tape\n");
        }
      }
    }
  }


  // SPECIAL CASE: Digital Integration has a weird bit when loading the
headers
  // that is not covered by the normal check. All we can do is check for an
  // AND #40 followed by a LD (HL),A or a OR n
  if( fStop )
  {
    chMem = m_lpZXDeviceContainer->MemoryRead( wAddr );
    if( chMem == AND_n )
    {
      chMem = m_lpZXDeviceContainer->MemoryRead( wAddr+1 );
      if( chMem == 0x40 )
      {
        chMem = m_lpZXDeviceContainer->MemoryRead( wAddr+2 );
        if( chMem == LD_xHL_A || chMem == OR_n )
        {
          fStop = FALSE;
          TRACE0("NOTE: Special case: DI header detected. Not stopping
tape\n");
        }
      }
    }
  }

  return !fStop;
}
