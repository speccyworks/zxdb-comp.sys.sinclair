The Gnome at Home BB.

Who recalls it? I had some pages on there and some telesoftware too. I also
remember the viewdata pictures, which were converted from grabbed bits of
Speccy screens by a very clever bit of software by Pat Reilly, known as
Patman. He also had a BB for a while which ran Micron software on a bank of
Microdrives and 2 Speccy machines networked via IF 1, it had an auto answer
modified VTX 5000, and used 1200 baud half duplex which the Modem 1000 for
the Beeb and the VTX could access. Worked fine till it got a faulty file on
the drive...

Talking of Half Duplex, we used to upload the Speccy stuff with the above
mode straight to Prestel's gateways at Croydon. Kind of nice to see a lil ol
Speccy telling a mainframe what to do.

It was not interactive, it was called bulk software, and was written by Mike
Sun.

By the way, does anyone have a copy of Dr Spectrum? A Lisa type artificial
intel. proggy that Patman used to run on his BB to help us run up the phone
bill.

2001-12-04 22:00:28 Dan Antohi 'New' hardware project: IF1_Bis
Hi everybody,

IF1-Bis is a project that took up a good part of my spare time for the last
four or five years. Now that it is practically completed, I couldn't resist
sharing it with other Spectrum hardware enthusiasts (just in case there are
any left).

It is, in essence, a 'better Interface 1', featuring: RAM disk, hard disk
and parallel printer port, also used to connect to a PC.

The full documentation, including the commented source code, is available
at: http://members.freemail.absa.co.za/dan_antohi/ or
http://www.icon.co.za/~dantohi/

Regards,
Dan
