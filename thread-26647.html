> which says the ports used are:-
>
> 64479 or 4929 = MouseX
> 65503 or 1951 = MouseY
> 64223 or 1751 = Buttons (bits 0 and 1)

The second set of ports looks a little suspect to me as the numbers don't
make alot of sense when converted to hex.

I've got a Datel Genius mouse which is kempston compatible and only responds
to the following port addresses:

xpos delta 0xfbdf
ypos delta 0xffdf
buttons  0xfadf ; active low (bit 1==left, bit 0==right, rest follows
floating bus)

ie. the first set of ports you mentioned. This is what I've implemented for
Spectaculator's mouse emulation. Art Studio 128 supports the kempston mouse
natively - you don't need any extra pokes.

Regards,
