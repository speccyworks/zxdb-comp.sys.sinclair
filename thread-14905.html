Rules

--------------------------------------------------------------------------------

These rules are not yet final but no changes will be made to them
after the 15th of March, so any queries should be sent to CSSCGC
before this date. 


Rule 1 
All games submitted must be written by you. If it is found that th
game has previously appeared in any computer magazine as a type in
listing it will be disqualified. Games inspired by games on other
systems are allowed.


Rule 2 
The competiton will run from March 15th 1999 until May 31st 1999,
inclusive. There will be NO extension to this time limit, (as I am off
to Japan at the end of June :-)), and the final results of the
competition will be posted here and on comp.sys.sinclair on the 15th
of June.


Rule 3 
The Judges decision, Graham Goring and myself, will be final and no
correspondence will be entered into.


Rule 4 
All entries should be supplied in a format that is readable by either
X128, Z80 or ZX32 as these are the emulators available to us. TZX is
the preferred format as it will be possible to test these on a real
Spectrum without too many problems. if this is not possible then use
TAP or Z80/SNA.


Rule 5 
You may write the game on whatever system you prefer as long as the
program works as detailed in Rule 4.


Rule 6 
If possible please add a loading screen to the TZX file.


Rule 7 
There will be no censorship so feel free to submit games on any
subject you like.



--------------------------------------------------------------------------------

Instructions: 

After writing your masterpiece send it to CSSCGC with the subject
heading "CSSCGC 1999 : Game Name Your Name", where Game Name is the
name of the game and Your Name is your name. Then check the entries
page a couple of days later to check whether the entry got through.
