Hello.

TZX 1.20 contains support for ZX81 type blocks. The Generalized Data block is
used to encode the ZX-81 data. Mike's great EightyOne uses this and you can
download the sample tzx files from his site/package.

The documentation is on World of Spectrum. look here :

http://www.worldofspectrum.org/TZXformat.html#GENDATA

There is also an example ZX81 encoding there.

Best regards,
 Tomaz
