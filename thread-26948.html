Hi Mike and All at CSS!

This is a starter for Adventure 200, a 200 location
text adventure originally release in 1982 for the
ZX-81 16k and ZX-Spectrum. It was published by a
company called, FOILKADE SOFTWARE (ceased trading now)
and was written by C.J.Coombs

*** Two of us have tried to complete this game since
1983/4 and we still haven't done it **
That's 20 years!!!

Can you help?

There was no SAVE facility in the game (very annoying)
so I use the zx32 spectrum emulator. You can then use
the ZX->Save as... menu to save the game at any point.

The game can be downloaded from WoS:-

http://www.worldofspectrum.org/infoseek.cgi?regexp=^Adventure+200$&pub=^C%2eJ%2e+Coombs$


Objective of the game
=====================

You start at the EAST gate of the PALACE. The objective is
to get all the treasures and enter the palace. If you enter
the palace and don't have all the treasure you are killed
by the King.

Commands used in the game
=========================

Very limited command set. (remember this fitted into 16k!!!)


DEscribe	<item>   	(give more info on an item)
DIg				(ermm. dig!)
DRInk 				(drink fresh water / or sea water!)
DRop 		<item>
LIght		<item> 		(i.e. light lamp)
LOck				(lock something)
Inventory			(lists items you are carrying)
Quit				(give up!)
TAke		<item>		(pick up an item)
THrow		<item>		(throw an item you are carrying)
UNlock				(unlock something)
View				(refresh screen)

That's it! All that's left is movement commands:-

N,S,E,W,NE,SE,SW,NW,UP and DOWN.

Suggestion and 1st objective
============================

You must make a map as you go along!!!

I would suggest that anyone that attempts this game should try
and get to the IRON BRIDGE with the TROLL guarding the way
with the following items in your inventory:-

FISH
AXE
COIN
LAMP (lit)
JUG


We can provide help here on CSS. Please put Adventure 200 in
the subject. Or email me: pbeilby 'at' yahoo 'dot' co 'dot' uk
(I hate spam and those scripts that parse newsgroups!!!)

Patrick/
