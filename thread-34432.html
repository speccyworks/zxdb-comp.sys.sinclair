10 posts, 2009-05-05 – 2009-05-12

2009-05-05 01:12:19 Nama ZXDB: Chopper Drop 3000
Hooray!!!

Finally, the ultimate high action helicopter flying experience for the
ZX81 has arrived.
A year and a half in the making (ok, I did take a break in the
middle), and with much help from Siggi and Andre***. (Andre*** sped up
my original basic coding, and Siggi helped with compiling the basic
into machine code using McoderII). I wanted to publicly thank the both
of you. THANKS!

the game has been tested on a real 16k ZX81, as well as ZXSP (OS X)
and EightyOne (Windows) emulators.

Chopper Drop 3000 game information can be found here:

http://web.mac.com/lord_philip/sinclair/ZX81_Chopper_Drop_3000.html

Two versions of the compiled game exist.
One version (CD3000.p) using my preferred keys (Q,A,O,P and  M)
and an 'alternative keyboard' version (CD3000ak.p) for the ZX81 purist
which uses the standard arrow configuration (5,6,7,8 and 0).
Both versions can be downloaded form from here, under the 'ZX81'
folder:

http://tiny.cc/0VbLD

Thanks for playing, and if you like our game, please let us know.

Philip (aka Nama)
