Notes:

In most respects the Spanish 128 Editor functions just like the British
128 Editor.
There are a number of differences:

1) There are no menus.

The calculator works from the command line (when the cursor is directly
above the info bar at the bottom of the screen). You can even do running
calculations in this mode. There is no auto-loader or tape-tester though.
Renumbering is possible with a new command.


2) The bar looks different.

The info bar tells you if you have CAPS LOCK, GRAPH or EXTEND mode selected.


3) Editor differences.

You cannot enter commands in lower case (unlike on the British version),
but you can enter control codes as in 48 Basic and they will show up with
pairs of stylized 'G's to show the presence of control codes. A syntax
error will be highlighted by a little bug UDG. Some of the bugs in the
British version are not present in this version. The EDIT key switches
from the main screen to the command line, rather than invoking menus.


4) New commands.

The Spanish editor has some new commands (which must be entered from the
command line, not the main screen).

DELETE n1,n2 - Remove lines from n1 to n2 from the listing.

RENUM [n1],[n2] - Renumber the listing starting at line n1 in increments
of n2. Default values for n1 and n2 are both 10.

EDIT - Switch to the main screen (like pressing the EDIT key).

EDIT n - Edit a given line number.

EDIT n$ - Call the text editor to edit a given string variable.

WIDTH [n1],[n2] - I have no idea what this is for. RS232 perhaps?


5) Built-in text editor.

The command EDIT a$ will open the text editor to change the contents of
a$. The screen will be cleared and the contents (if any) of a$ displayed
with an extended info bar at the bottom of the screen like this:

[LINE:    1  COL.:   1  WRAP ON  ]
[             MODE: INSERT       ]

If you select GRAPH or EXTEND mode they will show up under LINE: as usual.
LINE and COL are the cursor position. 'WRAP' selects if a word you are
typing at the edge of the screen should wrap around or not. You can turn
it on and off with [EXTEND]-Q. The three input modes are 'INSERT'
(default), 'AUTO MARGIN', and 'REPLACE'. The first will place text at the
cursor position, the second attempts to provide a left hand margin (with
varying success), and replace allows you to type over what you have
already typed. As with the BASIC editor, the text editor uses the extra
keypad functions and these are in the same place as on the British
version. Exit the editor by pressing the [EDIT] key.

Emulators split broadly into two camps. Those that have separate files for
each ROM and those that combine the ROMs for a given machine into one
file. (There are also those with all the ROMs for every machine in one
file and those that have the file embedded in the application). Philip's
site has the individual ROMs. SPIN obviously needs the combined file. So
to answer your question you need to stick ROM 0 and ROM 1 together in that
order. As Philip said you could concatenate them (which means doing that).
I think from DOS: COPY soure0.rom target.rom, followed by TYPE source1.rom
>> target.rom. will do the trick. However it's been a while since I've
used DOS. The alternative is to load both ROM's into the emulated
Spectrum's RAM area and save them out as one big chunk. I don't know if
SPIN lets you do this but other emulators do. just CLEAR 30000 and then
load ROM 0 in at 32768 and ROM 1 at 49152. Each ROM is 16K in length so
the combined file is 32K. I hope that helps a bit.
