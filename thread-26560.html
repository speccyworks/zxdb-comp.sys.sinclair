First, there has been a massive update to the Sinclair Basic site. This is
where you will find all of the files you need to run it on your machine,
real or emulated.

The site is at http://www.worldofspectrum.org/sinclairbasic/


Site changes:

Revised the History section.
Added a Unix based interpretter to the Versions section.
The SE Basic page has the latest versions for download.
The License is downloadable/viewable on-line.
The Source code is downloadable/viewable on-line.
Patches are provided to allow SE Basic to work with virtually any Spectrum.
Software only versions of SE Basic are provided for virtually any Spectrum.
Three SE Basic software titles to download including the SE Basic Compiler.


SE Basic version 0.80a summary:

Proper Open Source release.
Easier installation process.
Now runs on 16K, 48K and clones, 128K and clones, +2, +2A, +3, SAM Coupe.
Can be used in RAM instead of ROM on real machines.
Patches available so any version of the 128 editor will work properly.
Works with the Interface 1 and ZXATASP/ResiDOS.
There's a new font, a new tokenizer and a simplified keyboard layout.
The cursors go up and down in an edit line.
The reset is faster (works on 16K machines too!).
Line numbers up to 16383 are allowed.
Almost all of the bugs in the original ROM are fixed.
There's a faster square root routine.
The screen$ command can now hanle UDGs.
There are macros available on the keyboard via EXTEND-SYMB-6 to 0.
(Don't try and use macros with a 128 editor paged in - it will crash!)

There are many more minor features but too many to list.

Please report any bugs via email. Since the user base is still small I can
also answer any questions on how to use or install SE Basic. 

P.S. How many people are actually using SE Basic? Is it worth setting up a
user group? And is anyone interested in translating the Sinclair Basic
site into Spanish?

Cheers!

>SE Basic version 0.80a summary:

>Works with the Interface 1 and ZXATASP/ResiDOS.

Although SE Basic can open a network channel and PRINT or 
SAVE to it, it won't be able to CLOSE the channel as you've 
removed CLOSE_2.

Interface 1 depends on an instruction fetch on Main address 
$1708 to page itself in. The OPEN # command is invoked by 
RST 08 but not the CLOSE command which as we know crashes
with already closed channels.

After Interface 1 has closed the channel then it returns to 
Main ROM at   X16EB - the LD BC,$0000 instruction after the
call to CLOSE_2 and this has been displaced by three bytes.

128K Basic calls the 48K ROM routine to use Interface 1.

Bank switching is alchemy and Sinclair Research and 
Amstrad never managed to get it right with any of their Spectrum
incarnations.  The Amstrad CPC range was OK and designed as such.

The Sea Change ROM is strictly a single bank Operating system 
and to disable Interface 1, I disabled RST 08 and isolated address
$1708.
 
This is a list of Main ROM addresses that are required to be stable for
Interface 1. The Disciple and Opus interfaces will have similar lists as
will 128K BASIC.

DEFW    L0010           ; main PRINT_A
DEFW    L0018           ; main GET_CHAR
DEFW    L0020           ; main NEXT_CHAR
DEFW    L0030           ; main BC_SPACES
DEFW    X007B           ; x    TEMP_PTR3
DEFW    L02BF           ; main KEYBOARD
DEFW    X08CE           ; x    ME_CTRLX
DEFW    L0C10           ; main PO_TOKENS
DEFW    L0D4D           ; main TEMPS 
DEFW    L0D6B           ; main CLS 
DEFW    L0D6E           ; main CLS_LOWER
DEFW    L0ECD           ; main COPY_BUFF
DEFW    X0F85           ; x    ADD_CHRX
DEFW    L107F           ; Comp ED_ERROR
DEFW    X1349           ; x    comma space
DEFW    L15E6           ; main INPUT_AD
DEFW    L15FE           ; Comp call_sub
DEFW    L1601           ; main CHAN_OPEN
DEFW    L1655           ; main MAKE_ROOM
DEFW    L16B0           ; main SET_MIN 
DEFW    L16BF           ; main SET_WORK
DEFW    X16EB           ; x    CLOSEX
DEFW    $1708           ; MAIN "INC HL"
DEFW    L1727           ; main STR_DATA1
DEFW    L19E5           ; main RECLAIM_1
DEFW    L19E8           ; main RECLAIM_2
DEFW    L19FB           ; main E_LINE_NO 
DEFW    L1B7D           ; Push STMT_R_1 
DEFW    L1BF4           ; Push STMT_NEXT
DEFW    L1C82           ; main EXPT_1NUM
DEFW    L1C8C           ; main EXPT_EXP
DEFW    L1CE6           ; main USE_ZERO
DEFW    L1E94           ; main FIND_INT1
DEFW    L1E99           ; main FIND_INT2
DEFW    L1F05           ; main TEST_ROOM
DEFW    L28B2           ; main LOOK_VARS
DEFW    L2BF1           ; main STK_FETCH
DEFW    L2C8D           ; main ALPHA
DEFW    L2D28           ; main STACK_A
DEFW    L2DE3           ; main PRINT_FP

Here's the skinny on SE Basic 0.83c:


Issues:

This version breaks LIST and LLIST support in the 128 Editor. A patch
will eventually be made available but until then you should continue to use
version 0.80a.

This version also breaks SCREEN$ (n,n) support in the SE Basic Compiler.
This will be resolved by changing the ROM rather than patching the editor,
as soon as I work out what's happening in the compiler runtime. If this
causes you problems you should continue to use version 0.80a.

(This version doesn't fully support IF1)


Editor changes:

* Almost all the bugs are fixed.

* The machine resets much faster.

* 128-style copyright message.

* New 6x8 font for use in 32, 42, 64 and 85 column modes.

* The FREE MEMORY routine is relocated. Call it with:
  PRINT 65536 - USR 95.

* The NMI button calls a default Break routine or you can assign your own
  routine by poking the address into NMIADD.

* Keywords are now ANSI compatible.

* Simplified the keyboard. All the symbols are now available via symbol-
  shift and the normal key for that symbol. The copyright character is on
  the 'I' key which does not normally have a symbol.

* Added a tokenizer and removed 'K' mode. All keywords must be typed in
  full but macros are available for the most common ones. Commands and
  functions can be entered in upper, lower, or mixed case.

* Hid EXTEND mode. Normally has no function but can still be used to get
  in-line control codes and macros.

* Added macros to certain number keys with EXTEND+SYMBOL SHIFT:
  6 - RUN [ENTER]
  7 - SAVE "" [<-]
  9 - LOAD "" [ENTER]
  0 - CLS 56 [ENTER]

* Replaced the letter cursors with block colour cursors as follows:
  'L' - Blue
  'C' - Yellow
  'G' - Green
  '?' - Red

* Changed the error cursor to behave like the 128. If you enter a line with
  incorrect syntax, the machine beeps, the cursor goes red and jumps to
  where it thinks the error is.

* Extended the valid line range to 1-16383.

* Cursors can move up and down as well as left and right in an edit line.

* Since the 'STOP' token is removed from the keyboard, pressing cursor down
  during an INPUT A or INPUT A$ command will produce the token. It will
  still Break into the program as normal during an INPUT LINE A$ command.

* Changed the error messages and the way they are output. Whereas before
  you might have got the error:

  R Tape loading error, 10:1

  Now you would get:

  Loading error 10:1

* Prevented the keys V-Z from producing tokens in 'G' mode.

* Inverted the cursor so it shows up in 512x192 mode on Timex machines.

* Enhanced some of the commands and functions:

  CLS     - Now takes parameters. Works as normal without a parameter
            (defaults to CLS 0) but sets border and attributes with a value
            from 1 to 255. Produces 'Out of range' error with higher
            values.

  CONT    - Replaces CONTINUE. Works as normal.

  COPY    - Now a file command. Takes any syntax. Produces 'Bad device'
            error unless additional hardware connected.

  DEL     - Replaces ERASE. Now takes any syntax. Produces 'Bad device' 
            error unless additional hardware connected.

  DIR     - Replaces CAT. Now takes any syntax. Produces 'Bad device' error
            unless additional hardware connected.

  FORMAT  - Now takes any syntax. Produces 'Bad device' error unless
            additional hardware connected.

  GOTO    - Replaces GO TO. Works as normal.

  GOSUB   - Replaces GO SUB. Works as normal.

  LIST    - LIST only lists the line you name rather than the whole program
            starting at that line. The full syntax of LIST is:


            LIST [x][,[y]]


            where x is the starting line number (default 0) and y is the
            ending line number (default 16383). Produces 'Out of range'
            error with line numbers greater than 16383.

  LLIST   - Equivalent of the new LIST command only sent to stream #3. 

  MOVE    - Now takes any syntax. Produces 'Bad device' error unless 
            additional hardware connected.

  NEW     - Now takes parameters. Works as normal without a parameter
            (defaults to NEW 0). NEW 1 is the equivalent of PRINT USR 0.
            NEW n is the equivalent of CLEAR n: NEW. Produces 'Bad RAMTOP'
            error with values outside the range of CLEAR.

  SCREEN$ - Can now detect UDGs as well as normal ASCII characters. It
            cannot detect predefined graphics as there is no bitmap to
            compare them against.
