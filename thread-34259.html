Ok, here's my plug tax (50p and a Rolo wasn't it?). Has anyone tried
either of the Timex utilities I submitted to this year's CSSCGC?

ColorPRINT (on Page 4) is a Mode 2 font editor (which lets you use all
256 characters)

Mode 2 Tile Editor (on Page 5) is a Mode 2 tile editor (which lets you
edit 256 tiles of 16x16 each).

Mode 2, or hi-color mode, is a Timex display mode where the attribute
map takes up 6144 bytes instead of the normal 768 bytes, giving you
two colours per 8 pixels, instead of the normal two colours per
character.

ColorPRINT comes with routines for use in your own programs. The
editor has machine code source which you could adapt for use in your
own programs.

ColorPRINT is also available on WoS but I haven't submitted the editor
as it's still a work in progress at this point.

These tools were written for use in the development of the Spectrum SE
killer app.

Comments welcome.
