2012-12-09 16:40:58 Andrew Owen ZXDB: OpenSE BASIC
Fire up your virtual chocolate teapot for the first 32K version of SE Basic!

https://dl.dropbox.com/u/15659782/SE%20Basic%204.0.0.zip

You can use the lo-res ROM on its own in place of the standard ROM, but 
when running on a Spectrum SE you get glorious MODE 1.

"What's so glorious about MODE 1?" I hear you cry!

* How would you like to use Sinclair BASIC in a full hi-res 80x24 text mode?

* A small amount of original software will run after a fashion in this 
mode, notably the early Artic adventures.

* You'll never want to edit BASIC in 32x24 mode again.

Full instructions are included but I'm happy to answer any questions.
