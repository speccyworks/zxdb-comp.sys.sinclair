I have written a little messy weekend project that takes the ZX80 ROM 
and converts it into "C" code. The resulting code can be compiled with

The smallest ZX80 ever:

One goal is the smallest fully functioning ZX80 ever. The results of 
this experiment were surprisingly good, so I am considering recompiling 
a ZX80 into a PIC or AVR Microcontroller. These things are really tiny 
and really fast. So if I can have RAM and ROM on one chip and let the 
CPU do the video out, I could fit the whole machine including crystal 
and battery into the case of a Chinch connector. Just plug that into the 
AV of your TV and there's your ZX81.


The translator:

Please note that this is neither an emulator nor a JIT compiler. 
Instead, Z80 code is translated into a meta code which in turn is 
translated into another assembler or language, in this case "C". The 
advantages are truly native code and plenty of time to have the 
de/recompiler optimize for any platform. The disadvantage is of course 
that non-precompiled code segments will not work, i.e. loading a binary 
program without running it through the translation process will crash.

This is only a feasability test for a larger project, so the code is 
messy. Also, the resulting code is barely readable ;-). Still, 
recompiling the resulting C code with VisualC6 resulted in machine code 
12 times as large as the original ROM. Pretty good I'd say.

Just for giggles, here's some of the resulting (unoptimized) code (and 
yes, I know that some flags are handled wrong ;-) :


   //    ; ----------------------------
   //    ; THE 'INITIALIZATION' ROUTINE
   //    ; ----------------------------
   //    ; A holds $3F, HL holds $7FFF.
   //
   //    ;; RAM-FILL
   //    L0261:  LD      (HL),$01        ; fill location with 1 (null).
L0261:
   set_mem8(reg.hl, 0x01);
   //            DEC     HL              ; decrement address.
   reg.hl--;
   //            CP      H               ; compare address high byte to $3F.
   { uint8 t = reg.h;
     reg.sf = (((sint8)t) > ((sint8)reg.a));
     reg.zf = (t == reg.a);
     reg.hf = ((t-reg.a & 0x10) != (t & 0x10));
     reg.pf = ((reg.a-t & 0x80)==0x80);
     reg.nf = 1;
     reg.cf = (t > reg.a); }
   //            JR      NZ,L0261        ; back, while higher, to RAM-FILL.
   if (!reg.zf) goto L0261;
   //
   //    ;; RAM-READ
   //    L0267:  INC     HL              ; address the next higher location.
L0267:
   reg.hl++;
   //            DEC     (HL)            ; decrement to zero.
   { uint8 t = get_mem8(reg.hl);
     reg.pf = (t == 0x80);
     t--;
     reg.sf = ((t & 0x80) == 0x80);
     reg.zf = (t == 0);
     reg.hf = ((t & 0x1f) == 0x0f);
     reg.nf = 1;
     set_mem8(reg.hl, t); }
   //            JR      Z,L0267         ; back, if successful to RAM-READ.
   if (reg.zf) goto L0267;

> Oh, and of course: how do *you* get from Z80 to ARM code?

Easy.

R3-R9 = a,b,c,d,e,l,h
r10=PC, r11=SP, r12=base of Z80 memory

//    ; ----------------------------
   //    ; THE 'INITIALIZATION' ROUTINE
   //    ; ----------------------------
   //    ; A holds $3F, HL holds $7FFF.
   //
   //    ;; RAM-FILL
   //    L0261:  LD      (HL),$01        ; fill location with 1 (null).

L0261:
orr r0,r8,r9 lsl #8
mov [r12,r0],#1
   //            DEC     HL              ; decrement address.
subs r0,r0,#1
and r8,r0,#&ff
mov r9,r0,lsr #8
   //            CP      H               ; compare address high byte to
$3F.
cmp r3,r9
   //            JR      NZ,L0261        ; back, while higher, to
RAM-FILL.
bne L0261
   //
   //    ;; RAM-READ
   //    L0267:  INC     HL              ; address the next higher
location.
L0267:
orr r0,r8,r9 lsl #8
adds r0,r0,#1
and r8,r0,#&ff
mov r9,r0,lsr #8
   //            DEC     (HL)            ; decrement to zero.
ldrb r1,[r12,r0]
subs r1
strb r1,[r12,r0]
   //            JR      Z,L0267         ; back, if successful to
RAM-READ. 
beq L0267

tokeniser unless we really wanted to. More advanced chunks of the Basic 
interpreter (trigonometric functions, DEF FN...) would depend on how 
ambitious I was feeling.

need that could easily download the original ROM.

actually started.
