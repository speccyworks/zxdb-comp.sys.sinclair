A game engine for the Spectrum and Timex/Sinclair 2000 series
of computers, supporting the Sinclair Spectrum, TS2068, TC2068,
UK-2086, TC2048 and ZX Spectrum SE.

Now fully integrated into the z88dk C model.

New from V1.2.1: 

- Everything transferred to the z88dk model so that SP can be linked
  like any other C library. 
- Full support for IM 2 vectored interrupts. 
- Support for Kempston Mouse, AMX Mouse and TS2068 Joystick Mice
  added. 
- Initialization and keyboard scanning have been made less automatic
  to give you more control. 

Features: 
- Support for three video modes:  256x192 pixel + 32x24 colour
  (spectrum), 256x192 pixel + 32x192 colour (hi-colour), 512x192
  pixel monochrome (hi-res). 
- Any number, any size pixel-precise sprites. 
- Fast character-size background tiles. 
- A dynamic block memory allocator. 
- Full IM 2 vectored interrupt handling. 
- Keyboard scanning including an easy to use redefinable keys
  joystick. 
- Many joystick and mouse types supported. 
- Helper functions to compute screen addresses + a pattern flood
  filler. 
- (coming soon) Sound and music through the beeper and AY-3-8912
  chip.
