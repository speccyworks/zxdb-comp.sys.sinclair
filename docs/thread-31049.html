I've got the day off today (hurrah!), so I thought I should get this
Tipshop update done
while I have the chance.. It's only been slightly more than a couple of
weeks since the last
one, but it's still quite impressive (fnar? Ed) 

* A follow-up to the naming conventions update from last time - Thanks
(again) to
the Perl genius of Nick Humphries and a reasonable chunk of manual
checking and editing
by myself, all (well, 99%) of the games should now be listed with their
correct
publishers. This should hopefully solve any confusion over duplicate
named games
like Barbarian, as well as improving the accuracy of links from
Infoseek. The
names/Publishers are based on the information kept at WOS, so eternal
thanks and
praise must go to Martijn van der Heide and the rest of the maintainers
at WOS
for the offline copy of Infoseek's database which we used.

accordingly.
