  I have uploaded a first stab at a v5/v8 Z-machine for the Spectrum+3 to 
ftp://ftp.gmd.de/incoming/if-archive/zxzvm.tar.gz.  Doubtless it will get moved
to /if-archive/infocom/interpreters/ in the next few days.

  This is still a somewhat buggy release; I realised after uploading it that 
it still has some debug breakpoints in it (border changes colour and program
waits for a keypress) and the tokeniser is not all a tokeniser should be.
But since there are doubtless other bugs I've missed, I thought as many
people as possible should be given a chance to find them.
