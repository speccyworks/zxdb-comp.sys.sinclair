They are. You need Wheelie as a TAP or TZX file, otherwise it will
always be the same map in the first game. I think it got something to
do with that Wheelie is part basic, and misses a RAND 0 command at the
beginning of the basic code.

A lot of basic games suffers from this, and therefore some of them
starts the same way every time, if saved as a Z80 file.
