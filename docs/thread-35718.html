So... Has anything happened here in the last couple of months? Nah - not 
much. Cough

* Tipshop should now (mostly) be back up and running in its new WoS 
server home. Eternal thanks to Lee Fogarty for his superb work at 
getting all of this back up and running!

* I've HOPEFULLY re-processed the 3 or so months worth of updates and 
corrections that had been done from the last backup of a non-corrupted

with an alternate one to use until it is.
