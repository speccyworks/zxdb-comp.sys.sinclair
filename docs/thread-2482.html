REQUEST: Jet Set Willy editor - solution

1995-02-28 07:09:17 address hidden ZXDB: Jet Set Willy Editor
Old, good times ... The problem with colour codes in JSWEDIT gave me
opportunity to hack something again.

The instructions below apply to the following version of JSWEDIT :

JSWEDIT  SNA     49179 93-07-04   21:06

Analyzing code I found the following place, where program is calling
routine what is asking for codes (#86C3). It is done one or two times
case first attempt is wrong. When second attempt also fails, program
is performing JP #0000 - what is reset. 

 Dec   Hex   Code    Instruction
-----------------------------------
34476 #86AC DD218B85 LD   IX,#858B  ; All the addresses are
34480 #86B0 CDC386   CALL #86C3     ; as in Spectrum memory. 
34483 #86B3 CACA87   JP Z,#87CA     ; 
34486 #86B6 DD21AB85 LD   IX,#85AB  ;
34490 #86BA CDC386   CALL #86C3     ;
34493 #86BD CACA87   JP Z,#87CA     ;
34496 #86C0 C30000   JP   #0000     ;

To get rid of problem is enough to change conditional jump JP Z,#87CA
to unconditional JP #87CA. To do it you have to change byte at
address 34483 (#86B3) from 202 (#CA) to 195 (#C3) In BASIC it is
POKE 34483,195. But you can add this POKE only to BASIC loader of
saved game, what is rather not convenient. To make the change
permanent file JSWEDIT.SNA must be patched. You need binary file
editor with hex search function. Look for first sequence CA CA 87
(offset 0046CE from beginning of JSWEDIT.SNA file) and change first 
CA to C3, so sequence will be C3 CA 87.

 Dec   Hex   Code    Instruction
-----------------------------------
34483 #86B3 C3CA87   JP   #87CA     ; after change

For MSDOS machines there is a nice shareware binary editor HEDIT.
At ftp.nvg.unit.no there is program POKE-SNA what probably will be even 
better tool.

After change program is still asking for codes, but accepting whatever
combination of digits 1-4 typed in.
