Here's all the tips I have. These are not in the order you have to do
things, just in the order they appear in the magazines. The last one is a
60-second solution.

"" (Sinclair User: Jan,Apr,May,Jun.1985)
If Philip uses [the number associated with KP Codes] at Kingsdown he'll
discover much to his advantage. Also if you wish to get information from
Selcra you must always place a message on the board first - enter SELCRA
followed by the name of the organisation.
Calling Routledge will give important advice on those behind the swindle.
Also Perry's specific code is VIN15 - instead of INFRA - and will give
further routes for your investigation. SELCRA will not reveal all about
every company but follow the track of some large fruit and you may pip 537
at the post!
To gain access to Midminster Bank you can find a code at Seastar Travel to
help.
""

"" (Your Spectrum, Sep.1985)
If you're trying to break the bank, a short holiday may refresh you. (You'd
better watch out, though, that it's not at Her Majesty's pleasure!) Also,
watch out for Perry, there's more to him than meets the eye. As someone
says, catch you on the phones.
""

"" (Crash Feb.1986)
L.T. Perry & Co: tel. 493-5429; codes are VIN15 and INFRA.
Message board: tel. 746-4460; no code needed.
Reserve Manhattan Bank: tel. 010-1(212)-976-5757; the code is M8R. In
Kingsdown Polytechnic it will say RM7; ignore it, it is an old code.
A.R. Routledge & Co: tel. 930-7269; code CCYRP455.
Big Apple: tel. 010-1(212)-976-5858; code PIP537.
Vinchetta (UK): tel. 952-7001; code E2RA. The first time you ring disconnect
and try again.
Mills Dyson & Co: tel. 723-9293; code 6729.
R. Boon Ltd: tel. 348-1408; code 7Y4Y.
Seastar Travel Ltd: tel: 353-2104; no code needed.
Elwood Brother: tel. 010-1(212)-976-6868; the magic word is EBV1657.
Satatel: tel. 222-2196; code ST412.
Cilisy: tel. 363-4017; code 673281.
Craig Communications: tel. 837-1099; code CRC3. There is a second code for
Kingsdown Polytechnic; it is CL332.
""

"" (Crash Aug.1985)
[This following tip professes to solve the game in one paragraph, so I've
done a Rot13 conversion on it so you don't accidentally read it if you don't
want to.]
Svefg bs nyy lbh zhfg cubar gur erfreir Znaunggna Onax. Gur ahzore gb hfr vf
010-1(212)-976-5757. Cyrnfr abgr gung vg vf na Nzrevpna cubar ahzore fb gur
qvnyyvat gbar vf qvssrerag. Abj lbh zhfg ragre gur onax pbqr, juvpu vf Z8E,
gura gur genafsre pbqr GSGO24 gb genafsre sebz IVAPURGGN gb PBZQNGN. Gur
onax vf ZVQZVAFGRE, gur nzbhag $1500000 naq gur genafsre pbqr 2175.
The program now confirms the transfer and you have completed the game.
""
