Okay,
    SPIN goes into a more technical mode now, with the inclusion of a TZX
Editor/Creator. I'll be doing this in two stages - the first is the editor,
which will include basic block management (cut, copy, paste, insert,
delete[1]) and a block properties editor. (for Andy Barker's Archive Info
block needs).

    The creator will be a two job affair - create from scratch, grabbing
bytes from binary files, or from speccy RAM and building blocks from that -
the other part being a WAV/CSW converter. I'm intending releasing the new
version (so long as Woody's not halfway though anything) when the first half
is done - CSW/WAV conversion will take a little longer and will need to be
tested thoroughly.

    So my question: If you were creating a tzx from scratch, what
functionality would you want in the software to help? I realise that this is
a pretty open-ended question, but as far as I can see, there's not much more
to do than set up timing info and the data blocks' contents.

Anyone?

D.
