I've got 51291,0 for infinite lives (SU.122), but it doesn't say which
version it's for, so it's most likely for the 48K. It won't do any harm to
try it, though.

The "built-in cheat" which someone mentioned - but, rather unhelpfully,
neglected to describe - is given thus in YS.92:
"When the game loads, press SPACE to start, then Q to quit. Now type
IWANTANOMLETTE (sic) and the border should flash. Now start the game
again, and press C for a cheat menu. This probably only works on 128K
machines."

The incorrect spelling for "omelette" is also given in SU for the same
cheat, so presumably the programmer's spelling wasn't too hot - or maybe
there were only 14 bytes spare for the cheat code.
