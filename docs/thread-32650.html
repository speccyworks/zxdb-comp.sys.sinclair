Up scrolling:

ADD HL,DE     : Add DE to HL
POP DE            : Decrement DE reg.
LD BC,2DC      : Load 2dc to BC reg.
LDIR                 : Copy memory function
RET                   : return to basic

2006-10-26 19:31:29 GzavSnap [ASM-ZX81/TS1000] Artic ASM2 Assembler: Partial screen scrolling. ZXDB: Screen Scrolling
Hi !
To compile an assembler code with Artic ASM2, you had to specify the first
code memory address, using the "ORG" function.
In my exemple, this funtion was not specified, and code was compiled to  the
default address ... $5BE4/23524 !
The main problem, if you had to put this code in a basic program, your code
will be decay to 16514 if you had to delete the zero line (Main ASM2
program) and run it.
Your compiled code will be wrong because of "jump" functions will jump to
old $5Bxx memory segment, and your code will crash the computer.

Try this Code :

This Exemple repeate 19 times ($13) this scrolling
"@" is a label : shit + A (don't type anything else)

ORG +16514
00 00
 LD A,+19
 LD HL,(400C)
 LD DE,+99
 ADD HL,DE
 LD (DATA1),HL

 LD HL,(400C)
 LD DE,+66
 ADD HL,DE
 LD (DATA2),HL

@RET1
 LD HL,(DATA1)
 LD DE,(DATA2)
 LD BC,+693
 LDIR
 DEC A
 JP NZ RET1
 RET

@DATA1 00 00
@DATA2 00 00

and assemble it with "A" in ASM2 menu.
All jump and memory address (DATA1 and DATA2) will be right to put this line
in a 1 REM xxx at 16514.
first "00" and "00", are reserved to mask the end of this line with a "$76"
or "$76".
($76 (hexa) = +118 (dec) ... poke 16514,118 and poke 16515,118)

Basic program:
 ( ZxBasic http://dskcenter.free.fr/zxtools.html
   ZxText2P http://www.grok.co.uk by Chris Cowley)
