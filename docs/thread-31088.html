  You're right. The odd thing is that the sectors all appear to be present. 
Let's see... <hexedit hexedit>
  Ah. Whatever tool as used to image the DSK got it dead wrong, because the
sectors are numbered 0-8 not 1-9. 

  If you've got LibDsk 1.1.x installed, then you can fix the problem like
this: 

1. Create a .libdskrc file in your home directory (that's "My Documents" on 
a Windows system). Put the following lines in it:

[cf2_0]
Description = Incorrect CF2 image
Sides = Alt
Cylinders = 40
Heads = 1
Sectors = 9
SecBase = 0
SecSize = 512
DataRate = SD
RWGap = 42
FmtGap = 82
FM = N

2. Remove the incorrect sector info.

	dsktrans -otype raw -format cf2_0 snaprun.dsk snaprun.ufi

3. Generate new sector info.

	dsktrans snaprun.ufi snaprun2.dsk

  (operations 2 and 3 can also be done from the GUI front end (dsktool) if 
you have that installed).
