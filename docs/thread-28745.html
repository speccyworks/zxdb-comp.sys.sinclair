Hi there,

Just a quick note to mention that, while I haven't done much with the
hardware over the last year, I have done a little bit on the software
side, and there are now quite a few emulation options for the machine.
At present it can emulate:

ZX80
ZX81
ZX Spectrum 16K
ZX Spectrum 48K
TK95 (and any other custom ROMs, eg SE Basic)
Interface II ROMs (Planetoids etc)
Mikro Plus (Shadow of the Unicorn)
TC2048 (the base machine)
TC2068/UK2086 (including ROM carts)
BBC Basic
ZX Spectrum 128K

Currently, to build a ZX Spectrum SE you need a TC2048, TC2068, TS2068
or UK2086. But I'm hopeful that someone will eventually make a version
of SpeccyBob that is based on the ZXSE hardware description in the CSS
FAQ so people can actually buy one. I'm excited by the 7IC version at
http://aticatac.altervista.org/ Now if only I had an email address for
Lodo.

> Somebody is looking for me? ;)

Er, yes. Any chance of developing your minimal IC speccy up to ZX
Spectrum SE specification?

Here are some reasons you might want to consider doing this:

The SE folds in the architecture of the Spectrum 128 and the Timex
Sinclair machines, offering the best of both worlds in enhancements to
the original 48K machine (and a few extensions to that model like
extra memory and more video RAM).

It is *more* compatible with 48K software than the Spectrum 128 or the
Timex machines thanks to a custom ROM set (uses 48 Basic from the
original machine and a modified 128 editor ROM).

In addition to running 99% of Spectrum software it can also emulate
earlier Sinclair machines, Timex and other clones, and use custom ROMs
including IFII games, Mikro Plus, BBC Basic (thanks to an MMU that
allows 32K of RAM to be paged into the first 16K of the Z80's memory
map).

The specifications of the machine are fully detailed in the css faq at
http://www.worldofspectrum.org/faq/reference/sereference.htm

Fredrick Meunier, who is responsible for the Mac OS X port of FUSE, is
in the process of adding ZX Spectrum SE emulation to FUSE, which of
course means apps can be developed and tested on modern hardware
(TC2048 support was practically non-existent until Chris Cowley added
it to vbSpec, but now support is growing - once ZX Spectrum SE support
is in FUSE it shouldn't be long before it makes it to a Windows based
emulator).

SE Basic (http://www.worldofspectrum.org/sinclairbasic/sebasic.html)
has built in support for the ZX Spectrum SE's additional hardware. And
I can add support for any additional hardware you want to add, like
serial, parallel and IDE interfaces.

So, have I sold you on the idea? Hope so. I'd love to see the machine
really take off as a cheap super-spectrum. Particularly now the real
thing is becoming collectible and hence expensive. I'm wary of putting
my email address on usenet, but if you are interested I will.

> I saw the Speccy SE specification and I'm still trying to understand the
> Timex memory management...

Well, the Timex has three banks of 64K, pageable in 8K chunks. The
normal bank contains the 16K ROM and 48K of RAM. This can be paged
over with memory from the HOME or EX banks, but they are mutually
exclusive - you can't page in memory from the HOME and EX banks at the
same time. You decide which bank you want to use and then you tell the
machine which of the eight pages of 8K you want paged in. With the
boot configuration of the 128 memory this works as normal, but owing
to the extended hardware, if you page in upper memory from the 128
system, sometimes the Timex bank you want paged in doesn't actually
get paged in. Of course this is a limitation of the prototype and
there's no reason you have to include it in your machine. The other
thing to note is that the 128 memory of the ZX Spectrum SE actually
has 144K available. All the details are in the faq and if you have any
questions you can email me at my russian email address. It's the same
as my Australian one but you need to remove the 'inoz' before the @
and put 'mail.ru' after the @ instead of 'yahoo.com.au'.

> I'll try to implement all the functions but the
> different video modes are still a big problem.

I know the SpeccyBob video supports the 512x192 mode, so it's the
hi-color mode that will be trickier, but I think if you talk to Mike
Wynne he can explain how to do it. Also SpeccyBob still lets you
choose the border colour in 512x192 mode, whereas on a real Timex the
border is set according to the ink/paper choice. Still, I see no
reason to limit the machine to the original Timex specs. Also, a free
choice of ink/paper in this mode would be a benefit. The real trick is
to get the timing right so that mixed modes work, like the first half
of the screen in hi-colour and the second in hi-res for graphic
adventure games. Finally the ZX Spectrum SE has the Timex and Spectrum
128 screen pages so you end up with four chunks of 6912K available for
video which means up to three shadow screens in normal spectrum mode
or one shadow screen in hi-colour or hi-res mode.

Let me know if I can help in any way, and don't worry about how long
it takes as I'm going to New Zealand for at least a year so time
really isn't an issue for me.
