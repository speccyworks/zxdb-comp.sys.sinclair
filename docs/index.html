Using these pages

  • Every item links to the post that shows it: click a date or "post" to read it in its thread (the post is highlighted). ZXDB numbers and titles link to Spectrum Computing.
  • Each page has tabs, one per kind of item, and a box that filters the rows on the page.

What is here

  • Only the threads these pages cite (631 threads) are included, not the whole group. Spam is left out, and e-mail addresses are shown as …@….
  • The links from the whole group to ZXDB (9,914 links: announcements, POKEs, maps, solutions, Tipshop credits, contest posts), and the TZX threads, without post texts or addresses, can be downloaded as an SQLite file: css-links.sqlite (3 MB), described in css-links-README.md.
