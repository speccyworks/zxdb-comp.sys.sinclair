2003-04-01 19:25:02 John Elliott Re: CGC 2002 Results CSSCGC Crap Games Contest 2002
  So, I can now reveal how I created the Pre-School edition of S.O.S. 

  S.O.S. contains a built-in level editor. To activate it, lose all your
lives, so the screen message reads "Press fire!". Then hold down the keys
C,H,E,A,T. 

  Normally, you'd be told this on the victory screen[1]. But I took that 
message out of the Pre-School edition. Didn't want to make it too easy,
after all.
  The keys for the map editor are:

* Movement keys (eg: 5,6,7,8) - move around
* Fire: Draw currently selected object in current cell
* Symbol shift: Swap between lower and upper layers of the map
* M: Save changes
* N: Revert to last saved change
* SPACE: Choose current object. Use left/right keys to change what object is
 in the current cell.

        The bottom third of the screen displays:

        00001   - Z coordinate, 0 or 1      000158 - sprite, upper board
                                            000155 - sprite, lower board
        00043   - X coordinate
        00044   - Y coordinate          00000 - current object

  There's no sprite editor :-(

[1] And the victory screen isn't much to write home about. There's at least
2k of unused memory in the snapshot that could be used for a better one.
