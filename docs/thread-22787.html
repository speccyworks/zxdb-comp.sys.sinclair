2001-08-06 05:54:13 Equinox Tetrachloride Re: Help with cheats for Manic Miner
"Keith" <…@…> wrote:

> I've got the ZX Spectrum Emulator (I can't find a "brand-name" or
> anything), and have been playing Manic Miner again for fun.  In the
> FAQ is says that you can "POKE 35136,0 for infinite lives."  What does
> the POKE refer to?  I seem to remember that being a Spectrum BASIC
> keyword.  Am I right?

POKE x,y means put the value y in memory location x. Changing a single
memory location can give infinite lives in many games (i.e. changing a
"subtract one" instruction to a "do nothing" instruction). Read the emulator
docs about using the Multiface: this lets you carry out POKEs while not in
BASIC.
