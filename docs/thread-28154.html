Just thought I would mention that I decided to release the current
developmental version of SpeccyPlayer - the AY file player for a Real
Spectrum. 

http://www.crumblenet.co.uk/speccyplayer/

Just don't have the time these days to tinker with it, so not much of
an improvement on 0.1a, but I thought it worth releasing since there
will probably be minimal development (by me, at least) for a while now
:-(

All comments are still more than welcome, of course! I don't want to
abandon the project completely. I will find some time to continue
development at some point. 

Big thanks to everyone who has sent me feedback, both via the
newsgroups/forums and directly! It's really appreciated! I'm only
sorry I haven't been able to fix all the bugs in this release :-(

It's good to know that it's not just me that's interested in doing
this, and that others have been able to make use of it :-) 

Cheers all! 

Tim.
