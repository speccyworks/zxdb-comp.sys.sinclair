Hi everyone,

Forgive the long posting, but I thought that this might be of interest
to some people.

Back in 1985 when I bought Fahrenheit 3000 (Firebird Silver platform
game in a similar style to JSW), I accidentally discovered a cheat
mode which asked for a password. However, I never managed to figure
out how to use it. I intended writing in to one of the magazines to
ask them about it, but I never got around to it, so the cheat mode
has remained unknown until now.

Recently, though, Blood has been going on about hacking games, so I
asked him if he could figure this cheat mode out, and he has done!
I've therefore created an SGD entry for Fahrenheit 3000 which provides
the full details. Here it is.

THE SPECTRUM GAMES DATABASE

FAHRENHEIT 3000

PUBLISHER
Firebird (Silver range)

AUTHOR
Tim Williams, Softstone Ltd

YEAR
1985

CATEGORY
Platform game

DESCRIPTION
The central core of the Dragon nuclear reactor is on
 a direct course to meltdown... Radiation leakage is
  increasing every moment... Your only protection
   an anti-radiation suit, you must enter the
    reactor's chambers and close off all 64 pressure
     valves before the core reaches...
      FAHRENHEIT 3000!
(Text taken from the spine of the original inlay)

Basically this is a Jet Set Willy-style platform
game. You must go through all the screens, collecting
"packs". There is one pack per screen, and when you
have collected them all you must shut down the nuclear
reactor and then locate and eliminate the culprit who
was responsible for the meltdown in the first place.

CONTROLS
Fahrenheit 3000 may be played with a Kempston
joystick, or the following keys:
 LEFT = Q
RIGHT = W
 JUMP = SPACE
 QUIT = 0

INSTRUCTIONS (ORIGINAL INLAY CARD TEXT)
When you enter the Dragon (get it?) nuclear reactor,
you will have a limited time to reach all 64 pressure
valves (one in each of the reactor's chambers) and
shut them off before meltdown occurs. Some valves
may already be leaking radiation, in which case they
will appear green.
Contact with any leaking valve is fatal.
Core meltdown occurs when the radiation level
reaches the maximum - Fahrenheit 3000 - resulting
in disaster for you (and the end of the game).

HINTS/CHEATS

(For some pokes, see the end of this section)

TIPS
When you are attempting to collect the valves (packs),
you must be careful only to touch them when they're
red; when they're green (and they flick randomly
between red and green) they kill you. You have a few
seconds upon entering a room before they start
wavering between red and green, so if the pack is
close to a room exit, it's often well worth going out
of the exit and entering the room again, to touch the
pack before it becomes lethal. (This is useful in the
very first room, for instance.)

Note that in this game, lives equate to radiation
level: each time you die, the radiation increases by
one. This effectively means that you have 40 lives.

CHEAT MODE
There is a full cheat mode, which I (Richard Hallas)
discovered by accident in 1985, but only recently
(thanks to Lee Tonks) found out how to use!

To enter the cheat mode, press keys 6, 7, 8, 9 and 0
simultaneously. You must be careful to press 0 last,
because it will cause the game to quit unless you are
holding down all the other keys first. To make the
cheat mode easier to access, do a POKE 30370,2: this
will cause it to be activated when you press just 9,
rather than the default five-key combination.

There will be a brief border effect, and the following
message will appear on the screen:

HI TIM - PASSOWRD PLEASE...

(Yes, the spelling mistake is really there!) It then
waits for five consecutive keypresses (and this is what
Blood has recently figured out).

Basically it's a level-skip cheat; you can use it to go
to any level in the game. You have to enter a 3-letter
password and a 2-figure level code. The thing about the
password is that it doesn't have to be a particular
string - quite a few things will work.

When you type the password in, the code looks at the
first three letters and decides whether these two rules
are true:

1) Do the ASCII codes of the letters add up to 224?
2) Is the third letter a G? (all input is converted to
   capitals)

If all this is true, the game then jumps you to the
screen specified in the next two characters. This means
that various passwords will work, like JOG?? or FSG??
or DUG??. I suggest using JOG, because it's easy to
remember.

The next thing you have to do is to enter a level code
to jump to. This works as follows:

The 64 screens in the game are arranged in an 8x8 grid,
where each row and column is numbered from 1 to 8 from
the bottom left. Therefore, in terms of transporter
codes, the map looks like this:

81 82 83 84 85 86 87 88
71 72 73 74 75 76 77 78
61 62 63 64 65 66 67 68
51 52 53 54 55 56 57 58
41 42 43 44 45 46 47 48
31 32 33 34 35 36 37 38
21 22 23 24 25 26 27 28
11 12 13 14 15 16 17 18

So, the two figures in the password are y- and x-
coordinates on the map. For example, the top-right
room, 88, is the nuclear generator room. To jump to
the penultimate screen (the one to the left of it),
you would type JOG87 at the password prompt.

If you enter 9 as the x-coordinate, it's the same as
entering the first column of the next row up; so room
19 is actually room 21, 59 is 61 and so on. Be very
careful not to enter anything else that's illegal,
because you will almost certainly cause the game to
crash if you do!

POKES
POKE 30370,2: cheat mode is activated by pressing 9
POKE 30818,0: infinite lives
POKE 30116,#: # = number of packs left to collect

Thanks to Lee Tonks (Blood) for the infinite lives
and password pokes, and to Richard Hallas for the
number of packs poke.

GENERAL FACTS
There are various Jet Set Willy references in the game
(e.g. a room called "Mr. Smith Will Never See This").

NOTES
Superficially a fairly abysmal-looking game with
terrible graphics, Fahrenheit 3000 actually turns
out to be quite addictive and playable once you've
got used to it. However, it has one of most
disappointing endings of all Spectrum games!
