PHEW! I thought this update was NEVER getting done. There's been lots of
background maintenance work getting done on Tipshop since the last one,
which

* Thanks to the eternally skill Perl programming of Nick (Humphries,
for those not in
the know), and some added manual editing by me, the naming convention
for Tipshop
should match that of WOS. This shouldn't mean any greatly noticable
changes here,
