1998-04-13 …@… 
Newsgroups: comp.sys.sinclair, comp.sys.amstrad.8bit

  ZXZVM (Z80 Infocom interpreter) has now reached version 0.02.

New in this version:

* Interpreter core: Bug fixes to the lexical analyser, object management 
  and abbreviation expansion. All debugging breakpoints removed (I hope).

* Spectrum front end: A simple BASIC loader is now supplied.

* PCW16 front end: Newly created. You can now play v5/v8 Z-code files on 
  a PCW16.

  ZXZVM isn't really stable enough to distribute yet, but if you want to do
some alpha-testing, it's at:
