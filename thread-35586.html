Does anyone remember the Spectrum SE project?

9 posts, 2014-06-01 – 2014-08-19

2014-06-01 11:28:00 Andrew Owen 
Some Spanish guys are building an FPGA clone that will include Spectrum 
SE support (http://zxuno.speccy.org). Only it's called the Chloe 280SE 
now, for legal reasons, and includes ULAplus (the palette stuff that was 
talked about 14 years ago but not included in the prototype). The SE 
Basic project has been folded back in to the core project and SE Basic 
IV (4.0.7) includes an 80x24 character text mode (480x192 pixels), and 
support for esxDOS running on divMMC (a newer SD card based version of 
divIDE that is built into the clone). When, ok if, a production version 
of the zxuno is made avaialable I'll be publishing a custom template so 
folks can order an SE keyboard from WASD keyboards 
(http://www.wasdkeyboards.com). Not cheap, but Cherry MX blue mechanical 
keyswitch, so should be good for a couple of decades of heavy abuse.

I have one project on the back burner ... a custom ROM that uses Currah 
Microspeech to say everything that gets passed through the screen and 
keyboard channels. The idea is to make the majority of adventure games 
accessible to blind users.

I have one project under active development ... an advanced cRPG engine 
for the Spectrum +2A. More details here (and no FB account required): 
https://www.facebook.com/zxodus
