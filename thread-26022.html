ANN: SE Basic 0.71

1 posts, 2002-08-29 – 2002-08-29

2002-08-29 17:54:05 Andrew Owen 
Thanks to those who recently pointed out some bugs in earlier versions of
SE Basic there has been a minor upgrade. Specifically, Richard Kelsh
pointed out an oversight in expanding the line numbers to 16384 - that the
editor now has to count over five spaces instead of four. And Geoff
Wearmouth announced an error in the Incomplete ROM Assembly source file on
which SE Basic is based. As for Geoff's comments about the non-standard
instructions in the file, Chris Cowley had already pointed those out to
me, but I did change the bad labels. This version should introduce no new
incompatibilities. However ColorDraw still doesn't work, although it did
on version 0.58 (which was hand built with patches instead of from a
source file). I have been unable to find out why and would appreciate it
if anyone can figure it out. Travel With Trashman still won't load from
.TZX (it checks for modified ROMs) but will run from a hacked .TAP or a
snapshot. Also, one or two games get upset by the new font. I am not aware
of any other software incompatibilities so please send bug reports. Also,
many games which refused to work on the 128, even in 48 mode will now work
on the 128 hardware in 48 mode, and in some cases in 128 mode as well. The
ROM is available as source or as an IPS file. The normal distribution
restrictions apply. Email me if you want a copy.
