Knight-Tyme 48k on the +3

2 posts, 1994-11-18 – 1994-11-21

1994-11-18 00:05:00 John Elliott ZXDB: Knight Tyme
  This probably counts as following up to my own post, but since said post
was at about the time this group was created, I think I can risk it...

  The 48k version of Knight-Tyme won't work because it points I at an area of
ROM which it expects to contain FFh bytes, whereas on the +3 it contains 
zeroes. The first step is therefore to obtain a genuine Spectrum ROM 
(SPECTRUM.ROM in JPP.ZIP is ideal).
  Unfortunately, the interrupt vector pointing at FFFFh means that the 
byte at address 0 is also important. This byte is corrupted by the 
'overwriting ROM' bug (or one of them), so before using the ROM file do the
equivalent of POKE 13308,170:POKE 13309,4 (these values from memory).
  Only then will Knight-Tyme work, with the ROM file loaded into Bank 4, and
the game in nos. 5, 6 and 3. However the 'save position to tape' option won't
work, and the Multiface won't be usable.1
