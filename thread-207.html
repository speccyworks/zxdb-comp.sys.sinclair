I too have done a version of MicroEMACS which supports mice (code inspired 
by Godefroy's) and menus (all my own work; in fact the _asm file containing 
most of the window definitions is constructed by a MicroEMACS macro from a 
rather more compact and editable definition...) It also supports Things (in 
various ways --- uses Menu Extension and Scrap if present, execute Things 
from ^X$ etc) and has a few extra commands bolted on.

It also appears in a "nice" window which has "move" and "sleep" icons 
(though "sleep" only works if Qpac2 is installed.) It seems to work without 
the PE but I do not intend to support such use of it.

There are versions with messages in English, Dutch, German, French and 
Spanish (though some of the messages are English in all versions.)

It should be on its way to SJPD, Qubbesoft and Quanta within the next few 
days. I could send a copy to QLCF as well if someone gives me an address.
