This release is now available as an IPS file. The file, and a suitable
utility for your machine, can be downloaded at

There will be no further developments for at least six months because I
just don't have the time to work on it. However, this version has been in

to break with it (which is probably their fault and not mine).

Sorry about the restrictive licence but if you look at what happened with
the first public beta I'm sure you'll understand why it's there. The final
release will be covered by a more liberal licence, providing people don't
pester me for the next release.

Here's the documentation:

Sinclair Extended Basic (SE Basic*) Copyright 1996-2002 Andrew Owen.
All rights reserved. *SE Basic is a trademark of Andrew Owen.

Build 0.70T. Public Beta 2. Released 11/02/2002.

Archive contents: basic.ips, editor.ips, readme.txt


End user licence:

The user is granted the right to use these patch files to modify legally
obtained ROMs for personal use only. This archive and the files in it are

of this project - you have been warned. Source code is available on
request.


Features:

Fixed every known bug.

-65536, CHR$ 8, CHR$ 9, CLEAR-PRB, CLOSE #4, COLOUR COMMANDS, DEC-TO-FP,
DOUBLE STORE, EDIT, GOSUB, GOTO, LEADING SPACE, LIST, MAIN-4 (two bugs),
MOD-DIV, NMI, PLOT, PO-FETCH, PR-CC, RESTORE, ROM OVERWRITE, ROM SCROLL,
RUN, STACK, WAIT KEY

Overhauled the editor.

Replaced the keyword entry system with a tokeniser - there is no K mode.
All commands must be typed in full. Moved all the symbols to SYMBOL+letter
key combinations. Moved the copyright symbol to SYMBOL+I, and included
command words on SYMBOL+ Q (LOAD), W (RUN) and E (STOP). Removed EXTEND
mode for everything except control-codes. GRAPHICS mode produces no
characters for V-Z. Cursors will move up and down in an edit line. Line
numbers from 1-16383 are now valid. Renamed some commands - CAT becomes
DIR, CONTINUE becomes CONT, GO TO becomes GOTO, and GO SUB becomes GOSUB.
Replaced the error messages with a shorter set to free up some space in
the ROM.

A new typeface.

Replaced the original font with a monospaced version of Geneva designed to
for equal clarity in 8x8 character and 6x8 character displays. Added
experimental 42 column mode. This mode is not yet fully integrated with SE
Basic. The mode is initialised with RANDOMIZE USR 15204. Syntax is PRINT
#4;AT 0,0;"Hello world!". This will change, do not rely on any programs
you write using this mode to work on future releases.

Miscellaneous changes.

Removed redundant ZX81 and channels code. Added a 16K hardware test. Small
enhancements to tape handling, keyboard speed, RASP, cursor. A faster
reset routine. A longer copyright message.


To do:

Overhaul channels and streams to handle all I/O.
Add support for text/graphics windows.
Add support for 8-bit character sets. 
Faster CIRCLE routine with colour code.
Built-in support for 42 column text.
Text/graphics support for 512x192 mode on Timex and Pentagon.
Default NMI routine allowing LOAD/SAVE snapshots and POKE memory.


Compatiblity problems:

SE Basic can be used in place of 128 Basic with a modified version of the
original 128 editor. A patch is included. Please report any compatibility
problems to …@….

There are two IPS files in the archive. The editor patch should be applied
to zx128_0.rom. The basic patch must be applied to the original Spectrum
ROM. The 128 BASIC is radically different and so it is no wonder this
didn't work. Once you have the patched basic ROM you can rename it to
zx128_1.rom and use it in a 128 emulator. All the patch to the editor ROM
does is allow it to use SE Basic in place of 128 Basic.
