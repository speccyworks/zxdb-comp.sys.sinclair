Ok, here is a quick report...

I tried the ROM in 4 different varieties of spectrum: Issue 6 48k, 128k 
Toast rack and a +3 (4.1 ROM and +3e 1.11 ROM)

*48k*
I had no problems with this, I tried a couple of games (Strontium Dog 
and M L Dizzy).  I also just tried a couple of type ins.  I like the 
lack of single key entry, but I'm not all together keen on the new font.

*128k*
I overwrote the 48k section of the ROM with the SEbasic ROM.  There was 
no real testing done, I really just checked if it would boot and run a 
simple BASIC test.

*+3 and +3e*
Again the 48k ROM was written over with the SE BASIC ROM.  

In both the +3 and +3e entering the line:

10 PRINT "Hello"

In +3 BASIC would give the line:

10 T "Hello"

On screen.  When this was RUN it printed "Hello" and then gave an error, 
"0 Undefined Variable(c)10:1" Adding the line:

20 goto 10

Would display line 20 OK and the program would run.  Breaking the scroll 
would cause the error "D Bad filename(c) 10:1"

I'm not entirely sure the SEBASIC ROM is supposed to work with the +3(e) 
so I left the testing there.

I hope this may be of some use to you Andrew, and if there is anything 
else you would like tested on real hardware let me know, either on here 
or via email.

cheers
Dave

The 128 Editor (+3 Editor, whatever) doesn't work properly with the SE
Basic ROM - the tokens have moved, and so have the error messages. 
Although the wrong thing prints on screen, and the wrong error messages
display, everything else should work fine.  You can get around the token
problem by using the English Spanish 128 Editor, but the error message
problem persists.  Andrew did have a bug-fixed version of the 128 Editor
in development but this was put on hold (possibly abandoned) some time
ago.  The latest version I have also has problems with the error
messages.  There is likely to be some sort of compatibility fix in the
future, probably involving the English Spanish ROM, I think the official
line at the moment is to use the English Spanish one and make a best
guess at what all the error messages mean, or (better) just use the ROM
in 48K mode.  Yes it is annoying.  Yes Andrew does know :-)

The SAM's font isn't bad. I used it myself in the +4 ROM (if anyone
remembers that), but the one in the SE is based on a professionally
designed typeface, adjusted for the Spectrum's display. You may think it's
a bit narrow, but as well as the 85 column option, it is also possible to
fit bold, italic and bold-italic versions in the 8x8 grid without the
characters looking bunched up. These styles are all available in the
Artist III, which I may get around to releasing one of these days (once I
figure out how to add Amiga mouse support).
