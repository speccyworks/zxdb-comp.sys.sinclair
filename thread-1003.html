Availability of C68:

The near-latest C68 is available by ftp from:

ftp://maya.dei.unipd.it/pub/pub/sinclair_QL/C68_v4.12/
	(for the source and 4.12 runtimes)

ftp://maya.dei.unipd.it/pub/pub/sinclair_QL/incoming/C68v4.13a/
	(for the 4.13 runtimes)

(I was asked to announce this by Philippe Troin  who
apparently does not have Usenet access (yet.))

This site is mirrored at:

ftp://wuarchive.wustl.edu/systems/sinclair/binaries/QL/from-maya.dei.unipd.it/

WARNING: version 4.13a of the runtime 1 disk is badly broken. At the
time of writing this is what these two sites have, but this should
change shortly.


Additionally, I have made c68 available by anonymous ftp from:

	ftp://myrddin.chu.cam.ac.uk/pub/c68/

The runtime 1 disk here is the corrected version 4.13b; additionally
there is a file describing how to patch 4.13a to make it work
properly (though 4.13b fixes a couple of other bugs too.)

(Many thanks to Stephen Early for providing the necessary resources.)


Distribution Format:

All of the above sites keep C68 stored in the same way, in five large
zipfiles. Three of these are the runtime system, and each
approximately fill a 720Kb disk when inflated. The other two contain
the source to the entire system, and fill five or six disks. It's
usually more efficient to only extract the files one needs from these.

The program required to inflate the zipfiles is called 'unzip' and
this program is available in various forms at the sites mentioned
above.
