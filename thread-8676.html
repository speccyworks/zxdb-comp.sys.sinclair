Hello Speccy fans.

Well all this discussion about original speccy loaders and the hopeful
implementation new tape file format is very exciting.  

Even more exiting to avid Spectrum emulator freaks is to watch the
original loading in on Z80/x128 or whatever complete with coloured
stripe, counters and hyperloads that draw the screen infront of you
(Madmix).

If anyone is interested in dowloading some VOC files of full original
loaders I have supplied some on my web page under the downloads section.

Equinox,			Mikro-Gen
Firefly,			Ocean, Special FX
Frostbyte,			Mikro-Gen
Madmix - Pepsi Challange,	U.S. Gold
Monty On The Run,		Mikro-Gen
SirFred,			Mikro-Gen
Starbike,			Hmms (cant remember)
Terraquake He-Man,		Adventure Soft
Wizball,			Ocean

Unfortunately I dont have the BG services LTP interface and use my Sound
Blaster to sample in the VOCs.
I used readvoc which is part of registered Z80-305, readsb doesnt seem
to work as well.

The trouble with VOC files is that they are painfully huge and take up
from 5-10Mb of Hard drive space, roll on the new .TAP/.ZXS successor, be
it (.ZXT,.TPE (My idea)), or whatever should cope with all the little
bits that the current and popualar .TAP format won't handle, like Combat
School and Enduro Racer etc.....

If anyone fancies making these VOCs into .TAP files I would be grateful.
I don't mean loading the game in, snapping it and adding a loading
screens and claiming it to be a genuine .TAP file when in reality it is
simply a lamers apporoach to a .TAP file.
