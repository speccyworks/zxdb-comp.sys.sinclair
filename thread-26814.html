I've just uploaded a preveiw of Sinclair Extended Basic to the WoS
Sinclair Basic pages. This one just features an enhanced editor, no other
changes to the original ROM for maximum compatiblity, and there's no
license agreement. It's also the first reworking of the original ROM to
feature a detokenizer AFAIK (thanks to Richard Kelsh). If you write
programs in Basic, once you've used this ROM you'll never want to go back
to the 48K or 128K editors.

Features:

Colour cursors - like on the 128 only better.
Extend mode is gone - except for colour control codes.
Simplified keyboard - all the symbols are achievable with two key combinations.
Tokenizer - converts plain text to keywords.
Detokenizer - when you edit a line, keywords are converted back to plain text.
Error handler - jumps to the location of any syntax errors and beeps.
Cursors - can go up and down in an edit line.
New font - with 8 extra characters (ASCII 24-31).

Never look at a picture of a Spectrum keyboard when you're trying to
program again!

Download it from: http:///www.worldofspectrum.org/sinclairbasic/sebasic/

Merry Xmas!

-Andrew

(from Understanding Your Spectrum, by Dr. Ian Logan)

Whenever a prompt message such as "scroll?" or the cassette
messages appear [sic], the Spectrum waits for you to press a
key. The problem is that if you press the wrong key, things go
wrong. Pressing TRUE VIDEO, INV VIDEO, CAPS LOCK, GRAPHIC or
EXTEND MODE causes the previous edit line to appear at the
bottom of the screen, with the 48K flashing cursor (even on 128K
machines). This is because the KEY_INPUT subroutine at address
10A8 is designed to deal with CAPS LOCK, mode changing, and
colour control parameters, however this is inappropriate for
prompt messages.
