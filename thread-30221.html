Shooing the seagulls away from his grass, Darren Salt wrote:

> Next: guess why the images are JPEGs rather than PNGs or GIFs... ;-|

Believe me, I'm not happy about it either! This came about because the
Gallery generator I use only allows me to export them as JPEG.

I've been hunting for longer than I care to think about for something
which will allow me to QUICKLY do the following:

1. Read in a collection of BMPs (the screenshots saved using SPIN)
2. Create a web-friendly converted copy of those
3. Create a series of thumbnails for them
4. Create a single webpage linking those thumbnails to their larger
converted equivelants. This webpage should ideally allow me to add my
own text (for the email link)

The reason for these requirements is that I plan to capture a shed-load
more screenshots, and would like some quick way of updating the webpage
for when people contact me with resolved titles.

If someone can point me to a bit of freeware (Windows format) which can
let me have the thumbnails/full pictures in a non-JPG format, I'd be
tickled pink.

Or, if there's some dashed clever Java/Perl script which will
dynamically create a thumbnailed gallery based on GIF/PNG files stored
in a folder, that'd also be superb... I did try a PERL script, but it
was (annoyingly) far too complex for my requirements and didn't really
create what I was after.

Any suggestions will be gratefully received!

Not 100% certain, but I *think* those two steps can be done using the
batch converter built into XNView (www.xnview.com); XNView is worth
having anyway, as it allows one to view piccies in over 500 formats,
most of which you'll never even have heard of (it even recognises .SCR
files, although the FLASH attribute is not supported).  The one gripe
I have about it is that although the main prog recognises .SCR, the
batch converter doesn't, so XNView is at present only useful for
converting .SCRs one at a time (for batch conversion, as the first
step I use Gerton Lunter's CONVERT (driven by a DOS FOR command) to
convert them to GIFs)...
