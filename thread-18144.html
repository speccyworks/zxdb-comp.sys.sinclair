Hard disk on a Speccy - it's true!!

6 posts, 2000-05-25 – 2000-05-26

2000-05-25 13:34:59 garry lancaster 
Yes, it's true - you can now use a hard disk with a Spectrum!

I've been using the current system for about 6 months now, and I've
finally got around to setting up a website to show you what it's all
about. The URL is:

	http://www.spectrumplus3e.redhotant.com/

The system consists of a (very) simple 8-bit IDE interface (which
has been up on Pera Putnik's site for a good couple of years now)
together with an enhanced ROM for the +3 (or +2A) which allows you
to treat the hard disk as a number of standard +3DOS drives.

This site is for *REAL* Speccy users, so if you're not just interested
in playing old games on emulators, check it out!

Yeah, that's actually very simple - you just need to get hold of a
standard double-density 3.5" drive (although perhaps not so easy
these days, as they're mostly high-density) and a standard floppy
cable (*without* one of those silly PC "twists" in it), plug it in
and you're away.

Of course, you're limited to 173K or whatever it is unless you get
a different formatter proggy - luckily there's one I wrote on the
+3e site, together with a PC/DOS transfer program which is incredibly
handy.

Couple of things:

1. 128/grey +2 don't have a DOS built-in, so somebody's gotta write one

2. They only have 32K ROM total (+3/+2A has 64K), so no real space in
there (plus I think the ROMs are soldered to the board, not socketed)
This means a software-based solution (yuck!) or adding external ROM
(not easy...)

3. I have attempted to use the interface on an original 128 (with
simple test program), but it doesn't seem to reliably read or write
to the hard disk - there seems to be some sort of intermittent timing
problem.

Having said all that, if anyone wants to attempt such a feat, I'd be
happy to try and help.
